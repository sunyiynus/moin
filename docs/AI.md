# Moin AI 对话

Moin 使用 [Rig](https://github.com/0xPlaygrounds/rig) 构建内置 Agent。对话直接在现有浮窗中进行，支持流式回答、多轮上下文和可选的本地文档检索工具。它使用你配置的模型服务，不会自动下载或启动模型。

## 开始对话

1. 打开「设置 → AI 助手」，选择模型服务，填写服务地址和模型名称，然后保存。
2. 点击浮窗中的「AI 对话」，或按 `Ctrl+5`。macOS 对应 `Cmd+5`。
3. 在输入框中输入问题，按 Enter 发送。回答会逐步显示。

对话可以连续追问。「停止」或 Esc 结束当前生成，「新对话」或 `Ctrl+N` 创建新的会话。macOS 对应 `Cmd+N`。可以复制回答，再切回应用或文件搜索。浮窗仍由设置中的全局快捷键唤起和收起。

回答使用 `pulldown-cmark` 解析 Markdown，再由 GPUI 原生控件渲染。支持标题、段落、嵌套的有序与无序列表、任务列表、引用、分隔线、表格、围栏代码块，以及粗体、斜体、删除线、行内代码和链接等行内样式。提问同样按 Markdown 显示，代码块使用等宽字体。

流式生成时会持续更新当前回复的 Markdown；历史回复复用已解析的内容。尚未闭合的代码围栏也能显示已收到的正文。代码块支持独立复制，长代码和宽表格可横向滚动。HTTP/HTTPS 链接只在点击后交给系统浏览器打开，远程图片不会自动下载。

对话布局参考 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)：紧凑顶栏、靠右的用户消息、开放式助手回复和底部独立输入面板。命令记录默认收起，点击可查看脚本、目录及输出；失败记录自动展开。每条回答可单独复制，底部可返回最新内容。输入面板显示本地检索和命令执行状态，点击可打开 AI 设置。

设置按钮右侧的「单独窗口」会打开可移动、调整大小的普通窗口，打开后收起主浮窗；再次使用激活快捷键仍可唤起浮窗。独立窗口和浮窗只同步会话记录、命令结果和流式文本。每个窗口分别创建自己的 GPUI 根视图、输入框、Markdown 缓存和布局；输入草稿、焦点、会话选择、工具展开状态和滚动位置各自独立。调整一个窗口的尺寸不会改变另一个窗口的组件状态。「浮窗对话」可从独立窗口重新打开浮窗。关闭独立窗口不会删除会话或停止任务。

左侧会话列表支持新建、切换和删除，标题取自首次提问。各会话的历史、草稿、运行任务彼此独立；切换或新建不会取消原会话正在执行的任务，运行中的会话带状态标记。停止按钮只结束当前会话任务；删除会话会同时结束该会话任务。

聊天记录保存在当前进程内存中，退出 Moin 后不会保留。停止生成的片段仍可查看，但不加入后续对话上下文。每次请求最多携带最近 24 条消息、48,000 字符的历史，单条问题最多 16,000 字符。AI 设置保存在应用数据目录 `config.toml` 的 `[ai]` 表中；保存新设置会结束所有会话的生成并清空上下文，已有显示记录保留，后续请求使用新配置。两个对话窗口均沿用主浮窗的透明亚克力背景。

## 显示设置

在「设置 → 外观」可以分别调整两组字体：

- **AI 对话字体**只影响对话中的提问、回答、Markdown 内容和输入框。
- **界面字体**影响搜索框、结果列表、设置窗口等其余文字。

每组都可以填写字体名称并调整字号。字体名称留空时使用系统字体；AI 对话字体留空时跟随界面字体。下方提供预览，保存后两个窗口会立即使用新设置。外观设置保存在 `config.toml` 的 `[appearance]` 表，模型配置在同一文件的 `[ai]` 表。

## 本地 Ollama

先在本机安装、启动 Ollama，并安装你要使用的聊天模型。模型名必须和本机已有模型一致；例如已安装 `qwen2.5:3b` 时，可填写以下设置：

| 字段 | 内容 |
| --- | --- |
| 模型服务 | Ollama |
| 服务地址 | `http://127.0.0.1:11434` |
| 模型名称 | `qwen2.5:3b` |

地址填写 Ollama 服务根地址，不包含 `/api/chat`。Moin 通过 Rig 的 Ollama 原生接口调用 `/api/chat`。本机 Ollama 不需要 API Key。

## OpenAI 兼容服务

选择「OpenAI 兼容」，填写服务商提供的 API 根地址和模型 ID。根地址通常以 `/v1` 结尾；不要填完整的 `/chat/completions`。此模式使用 Chat Completions 协议，服务需要支持流式响应。

「API Key 环境变量名」填写保存凭据的变量名，例如 `OPENAI_API_KEY`，不要填写密钥本身。Moin 从自己的进程环境读取变量值，`config.toml` 的 `[ai]` 表只保存变量名。远程服务必须提供有效的凭据环境变量；无鉴权的本机兼容服务可以留空。

例如从终端设置当前会话的变量后启动 Moin：

```powershell
# Windows PowerShell
$env:OPENAI_API_KEY = "你的 API Key"
.\target\release\moin.exe
```

```sh
# macOS
export OPENAI_API_KEY="你的 API Key"
./target/release/moin
```

环境变量在进程启动时继承。如果 Moin 已在托盘或菜单栏运行，先从菜单退出，再从包含该变量的环境启动。macOS 从 Finder 启动的应用不会自动继承终端的 `export`。

## 使用本地文档

在「AI 助手」设置中启用「允许检索本地文档」后，Agent 会获得 `search_local_documents` 工具，可按问题检索 Moin 已建立的索引。工具复用 SQLite 关键词检索与 LanceDB 向量检索，每次最多返回 5 个片段，包含文件路径和片段编号。浮窗显示实际检索到的来源，便于核对。

这个开关默认关闭。启用后，检索到的正文片段会随对话发送给所选模型服务；选择本机 Ollama 时发往本机，选择远程服务时发往该服务。文件目录范围仍由「索引」设置决定。要检索新的文件，先添加索引目录并更新索引。

检索结果作为参考资料交给模型，文件内容中的指令不会成为 Agent 的系统指令。

## 执行命令与脚本

在「设置 → AI 助手 → 任务执行」打开「允许执行本机命令」，填写工作目录并保存。此后 Agent 可调用 `execute_command`，根据真实的标准输出、错误输出和退出码继续任务，每次提问最多进行 16 轮模型调用。模型需要支持工具调用。

Windows 使用系统 PowerShell，可执行多行脚本、外部程序，也可用 `& '完整路径.ps1'` 调用脚本文件。macOS 默认使用 `/bin/sh`；安装 `pwsh` 后也可使用 PowerShell。每次调用都是独立会话，切换目录或设置进程变量不会影响下次调用。工作目录留空使用用户主目录，也可指定现有的绝对路径。

对话中显示执行的命令、目录、运行状态及结果。命令以当前用户权限运行，可以修改文件；输出会传给所选模型服务。开关默认关闭，不会自动提权或绕过系统脚本执行策略。点击「停止生成」会结束当前命令及其子进程；已发生的文件修改不会撤销。后台常驻进程不保留。

单条命令默认超时 60 秒，模型可指定 1–120 秒；开启命令功能时单次任务最长 10 分钟。标准输出、错误输出各保留最多 64 KiB，超出部分截断；超时时返回超时状态。

检索需要模型支持工具调用。普通对话不要求此能力；若模型不支持工具调用，可以关闭文档检索后继续聊天。未检索到依据时，Agent 应说明依据不足，不能把回答视为原文。

## 配置文件

可以在设置中打开数据目录。所有界面设置都保存在数据目录的 `config.toml`：索引目录、快捷键、最近应用、外观、Everything 和 AI 都在同一个文件里。下面是 AI 部分的示例；将 `model` 替换为本机安装的名称：

```toml
[ai]
provider = "ollama"
base_url = "http://127.0.0.1:11434"
model = "qwen2.5:3b"
api_key_env = "OPENAI_API_KEY"
system_prompt = ""
use_local_documents = false
allow_commands = false
command_working_directory = ""
```

OpenAI 兼容服务的 `provider` 为 `open_ai_compatible`。`system_prompt` 可填写自定义角色指令，留空使用 Moin 的默认角色。界面保存会验证配置；手工修改 `config.toml` 后重启 Moin。旧版本的 `config.json`、`ai.json` 和 `embeddings.json` 会在首次启动时自动合并到 `config.toml`。

如需 Ollama 神经网络向量检索，可在同一文件添加：

```toml
[embedding]
model = "bge-m3"
endpoint = "http://127.0.0.1:11434/api/embed"
```

普通对话每次请求总超时为 120 秒，启用命令执行后为 10 分钟，回答最多 64,000 字符。连接失败、服务拒绝、模型不存在、超时等情况会在浮窗显示错误，已有应用和文件搜索仍可使用。
